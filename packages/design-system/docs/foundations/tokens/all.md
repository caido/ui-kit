# All tokens

Every token in the system, with the value it resolves to in each theme.

This page is a reference. It is here so you can check what a name resolves to, or find a token when you know roughly what you want. It is not the place to learn which token to reach for. The foundation pages carry that, and each one shows its tokens as colours rather than as values.

A token marked `same` holds one value in both themes.
